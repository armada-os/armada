# AYN Odin 3 controller glyphs

This directory contains the AYN Odin 3 controller artwork and button glyphs
used by Armada Control. Armada compiles the assets into the Decky plugin, so
CSS Loader and a separate theme installation are not required.

The Odin 3 device profile selects the artwork automatically. Armada Control
offers two face-button styles:

- **Monochrome** (default)
- **Rainbow**

Only Odin 3 assets and styles are included here. Other handheld profiles are
not part of this integration.

The theme is derived from
[Handheld Controller Glyphs](https://github.com/victor-borges/handheld-controller-glyphs)
and remains licensed under the included MIT license.

See [ODIN3-ASSET-NOTES.md](ODIN3-ASSET-NOTES.md) for dimensions and button
mapping.
